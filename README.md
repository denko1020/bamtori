# 뱀토리 — 3D 모형

브라우저에서 돌려 보는 단일 파일 three.js 모형입니다. 설치할 것이 없고 링크만 열면 됩니다.

**보기 — https://denko1020.github.io/bamtori/**

## 조작

- 끌기 = 돌리기 · 휠 = 확대 · 오른쪽 끌기 = 옮기기
- 시점 — 비스듬 · 정면 · 옆 · 얼굴 · 위
- 동작
  - **귀엽게 춤** — 통통 뛰며 좌우로 살랑, 고개 갸웃, 브이 손 흔들기. 열여섯 박마다 한 바퀴 콩
  - **막대사탕 🍭** — 두 박마다 사탕을 입꼬리로 가져가 할짝, 가끔 "냠"
- 표정 — **귀여운**(윙크) · **놀란**(동그란 눈, O 입, "!!") · **졸린**(처진 눈, 꾸벅꾸벅, Z, 가끔 하품)
- **에오** — 고개를 갸웃하며 "에오" 말풍선
- 토글 — 움직임 · 빙글빙글 · 반짝이 · 이름표
- 빠르기 막대 — 분당 70~150박 (기본 104)
- 오른쪽 표의 줄을 누르면 그 부품만 남고 나머지가 흐려집니다

## 모형

- 비율은 [하치와레 3D 모형](https://github.com/pujune/hachiware-guitar-3d) 기준 머리 1.00 · 몸 0.65, 전체 0.85 배 (실제 머리 56 · 몸통 20)
- 허리까지 오는 진갈색 긴 머리, 눈썹을 덮는 일자 앞머리, 어깨 앞으로 내려오는 옆머리
- 앞머리 왼쪽 위에 하얀 물개 머리핀
- 큰 갈색 눈, 빗금 볼, 크림색 오버핏 골지 니트, 남색 주름치마, 흰 양말, 갈색 메리제인
- 왼손 브이, 오른손 막대사탕
- 무대 위에 골든 리트리버와 웰시코기 (흰 털에 아주 연한 베이지)

## 안에 든 것

- `index.html` — 모형과 조작, 설명판이 한 파일에 들어 있습니다
- `vendor/three.min.js` · `vendor/OrbitControls.js` — three.js r128 (MIT). 외부 요청이 없도록 저장소 안에 두었습니다
